## 🚀 About Me

I'm **Vedant Kulkarni**, a passionate **Full-Stack Developer** and **AI enthusiast** currently gaining hands-on experience through high-impact internships at **Nasdaq** and the **India Meteorological Department (IMD)**.

My focus is on bridging the gap between robust **full-stack engineering** and **data-driven intelligence** to create scalable, efficient, and innovative solutions.

- **Full-Stack Development:** Designing and deploying **robust, scalable web applications** with modern MERN/PERN stacks.
