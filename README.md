## 🤖 GenAI Log Analyzer

An AI-assisted debugging platform designed to help engineers investigate application failures faster.

**What it does**

- Parses and analyzes application logs
- Identifies recurring error patterns
- Generates investigation summaries
- Uses LLMs for root-cause exploration
- Retrieves relevant historical context
- Provides a developer-friendly interface for investigation

**Architecture**

`React → FastAPI → Log Processing → Retrieval → LLM → Analysis`

**Stack**

`Python` · `FastAPI` · `LLMs` · `Vector Search` · `React`

# 🧪 Engineering Philosophy

I care about more than just making something work.

### I try to build software that is:

**Reliable**  
Handles failures instead of assuming everything goes right.

**Understandable**  
Simple enough that another engineer can maintain it.

**Observable**  
Failures should be diagnosable.

**Automated**  
Repetitive work should become software.

**Scalable**  
Architecture should account for how the system grows.
