## 🧑‍💻 About Me

I'm a passionate **Full-Stack Developer** and **AI enthusiast** currently building high-impact solutions at **Nasdaq** and the **India Meteorological Department (IMD)**.

I specialize in bridging robust **full-stack engineering** with **data-driven intelligence** to create scalable, efficient, and innovative solutions.

### 🎯 What I Do
- **Full-Stack Engineering** — Architecting and deploying robust web applications with modern MERN/PERN stacks
- **AI & Data Engineering** — Leveraging meteorological data and ML models for real-world forecasting challenges  
- **Operational Efficiency** — Building automation tools that streamline debugging and enhance system stability

### 🔭 Currently Building
- **Gen AI Log Analyzer** — A Generative AI tool automating log analysis to dramatically reduce system debugging time
- **Solar Radiation Platform (IMD)** — A forecasting platform using **30+ years of historical data** to improve solar energy predictions
